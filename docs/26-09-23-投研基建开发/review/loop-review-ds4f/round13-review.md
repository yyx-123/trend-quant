## 主审人的处理

本轮没有"新机制缺陷"，三条 P2 全部是修复闭环不严造成的，故处理原则是**补闭环而不是加机制**：
把闸门补到漏掉的**读取面与旁路写入面**、把影子账户与清单口径**对齐逐笔 T+1**、
把跨进程可见性做成**哨兵文件**（并对崩溃残留设过期），同时把两处**失真的报告/提交信息**
逐条更正——这类"声称与实际不符"比代码缺陷更值得记录，因为它会误导后续审查。
