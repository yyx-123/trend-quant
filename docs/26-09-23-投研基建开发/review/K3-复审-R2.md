### K3-P1-1 停牌日 tail 卖出崩溃 —— 已修复，探针实证

**代码**：`engine.py:131-144`——tail 分支 `bar_close is None` 时不再 raise，直接构造

**我的探针**（与盲审轮同一崩溃用例）：

```
Engine.sell(fill_mode="tail", card=TradabilityCard(suspended=True), bar_close=None)
→ status=unfilled, reason=suspended   # 盲审轮为 CRASH(ValueError)
```

**钉子**：`test_review_k3ds.py::test_tail_sell_on_suspended_day_records_unfilled`
（引擎级：持仓保留 + unfilled 落账）+
`test_suspended_tail_sell_inside_run_continues`（集成级：40 日窗口中段停牌 5 日、
time_stop 到期日落入停牌区 → run 完成且 unfilled 含 suspended）——集成钉复刻的
正是我报告的触发形态（time_stop 不查当日 bar），具备可失败性。

### K3-P1-2 holdout token 断线 —— 已修复

**代码**：`pipeline.py:35-36` + `_pick_unconsumed_token`（:70-80）——调用方未显式传
token 时自动带出「绑定该实验（或全局）的最早未消费 token」，worker/CLI/MCP 由此
全部接通；CLI 另有 `--token` 显式透传。
**钉子**：`test_holdout_grant_to_run_end_to_end` 覆盖 无 token→failed / 发放→跑通
→consumed_at 非空 / holdout_touched=1 / warnings 留痕 全链。
**注记**：全局 token 的自动带出语义见 R2-注记-2（不阻断）。
