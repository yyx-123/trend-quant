## 1. 结论摘要（TL;DR）

1. **策略层答案**：用常规机制构建的组合策略 PM-v1（ETF 池 + MACD 金叉 +
   等风险 0.75% + 10 槽位 + 组合热 6% + 硬止损 1.5×ATR）**没有跑赢买入持有的
   风险调整收益**：全样本（2015-2024）ΔSharpe = −0.04（配对 t=−0.38），
   三个子窗口与 walk-forward 四折全部 inconclusive（t 均 < 0.5）。
   它的画像清晰：**"减亏型"**——2015-2018 段回撤浅 3.4pp、2022-2024 段回撤浅
   7.9pp，结构牛段（2019-2021，年化 +24%）与躺平打平；没有任何窗口产生显著超额。
2. **机制归因**（本课题真正的产出）：
   - 入场信号本身无短程 edge：MACD 金叉 7,393 事件的前瞻收益与无条件分布
     几乎无差（5/10 日 Δ≈0，20/40 日仅 +0.4%/+0.6%）——组合的平庸**首先归因于
     信号**，其次才是仓位（E0003）；
   - **硬止损不跟随利润**：round trips 中多数交易恰以 −1R 离场，含 MFE +113%/+
     148% 的长持单——利润全数回吐后仍打止损（E0001）；
   - **组合热窒息**：heat 把浮盈当作回吐风险，浮盈越大 heat 越大、新开仓越难
     通过——10 年拦截 10,404 次开仓意图，与 slot_limit 合计拦 24,872 次，
     10 年只成交 26 笔（E0001）；
   - **大盘闸门"减亏不增分"**：拦截 91,663 次开仓换来回撤改善 6pp，代价是
     SMA200 上方段少赚 5.8pp/年（E0005）；
   - **风险预算 0.4%-0.6% 是参数高原**（ΔSharpe +0.10，邻域同向、无孤峰）但
     配对 t=0.84 不显著（E0002）；
   - **震荡段磨损**：2022-2024 换手率 20.8（结构牛段 1.0），MACD 假信号在
     震荡段的摩擦成本是"减亏"被吃掉的主因（E0009）。
3. **平台验收答案**：投研平台全流程一次走通（AI 会话 → 建课题 → 提实验 →
   回测 → 平台 verdict → confirm → 关题 → 课题文件夹物化），纪律机制真实生效，
   判定器全家桶工作正常；发现 1 个阻塞性缺陷（below_min_order 落库崩溃，
   详见 §6-B1）与若干非阻塞问题（§6）。无晋升：没有任何实验达到 confirmed
   入库门——晋升门如实挡住了 inconclusive 策略。
4. **holdout 纪律**：全部实验严格限制在 sample 窗口（2015-01-01 ~ 2024-12-31），
   [2025-01-01, now) 的 holdout 未触碰（AI 无 token，按设计留给人工放行）。

## 7. 经验教训（为优化流程准备）

1. **L1 创建型失败时改进链没有锚**：改进型实验的 base 必须是库内 confirmed
   版本，PM-v1 inconclusive 后"先创建再优化"的直觉路径走不通。机制研究直接
   挂库内 base-v1 更稳；想孵化新策略线时要接受"第一版可能进不了库"。
2. **L2 先冒烟再全样本**：新机制×新定量的组合会走到系统未测过的角落
   （吊灯→below_min_order）。今后：新配置先跑 2022-2024 短窗口（秒级-分钟级）
   确认可完成，再投全样本。本次 E0004 直接全样本，代价 16 分钟。
3. **L3 成本结构决定实验设计**：全池参数类实验（含高原探针）~77 分钟，
   ETF 池同类 ~40 秒。模块互换类 diff 不带数值参数可省探针成本；股票池实验
   要给足时间预算或等 N4 性能问题解决。
4. **L4 parent 链在提案确认 ID 后再写**：实验 ID 按提案顺序分配，与本地
   spec 文件名编号必然错位（本次 E0003=event_study，E0004 才是吊灯）。
5. **L5 并行策略**：回测实验串行（共享 SQLite 写路径，避免工程失败污染台账）；
   event_study 等向量化模块可与回测并行（本次实测无冲突）。
6. **L6 inconclusive 纪律的价值**：8/8 inconclusive 的课题依然产出真知
   （病灶定位、机制画像、可执行性证据）——平台杜绝了"看起来赢了就说赢"，
   这正是首轮试验最需要保护的。
7. **L7 regime 拆分是"减亏型"结论的最佳证据面**：保护来自哪、成本付在哪
   （闸门：下方 +5.3pp / 上方 −5.8pp）一行可读，优于任何单一总量指标。
