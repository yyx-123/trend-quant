## 0. 分期判断原则（继承自原一期二期边界文档）

（原分期文档中"收进一期的 10 项及其理由"表见 git 历史 commit `a43d173`；
本文件保留原则与二期/暂缓项，一期项已落进架构稿 §4 阶段表与详设 §8。）

1. 硬依赖决定顺序，不决定分期归属；
2. "现在没有使用场景"不等于"不做"——便宜且协议已预留的件，随对应阶段
   顺手做；
3. 正确性验证成本高的件（统计判定器）不因贵推迟，但单独成任务、配
   golden 测试——统计件错了不崩溃，只会让结论安静地撒谎；
4. **结构性边界才构成暂缓**：无数据源、无实盘价值、动引擎核心、需要
   存量（多策略、实验历史）才有意义。

## 1. 二期项（结构性边界，触发条件驱动）

| 项 | 不做的理由 | 启动触发条件 |
|---|---|---|
| 工业化因子生产（表达式 DSL、因子库、相关性聚类、IC 流水线） | 决策 12：先把仓位/止损/组合风控做到及格 | 一期完成且基础研究线稳定后 |
| 加仓 lot 账 / 金字塔 / 网格模板 | 动引擎核心不变量（持仓模型、T+1 按批、round-trip 归因、网格无止损语义） | 引擎经基准 v1 验证后——二期第一件事 |
| 数据线（年度龙头池、退市股、历史拉深、ST/指数成分元数据） | 慢活：数据源能力验证（TickFlow 退市股/历史市值）先行 | **并行慢线**，不阻塞一期（龙头判定规则、退市股能力、拉深节奏三个遗留问题启动时再定） |
| meta-portfolio（策略组合/策略级轮换） | 需要多策略存量才有对象 | 策略库有 ≥3 条实盘级策略后 |
| 组合优化类 sizing（稳健优化/风险分解/反向优化） | 需协方差估计与优化器依赖；等风险够用 | 等风险被实验证明不够时 |
| 冲击成本滑点模型（量/波动率函数） | 小资金用不上；固定滑点+对账标定够 | 资金规模扩大到量级变化时 |
| purged/embargoed CV（净化交叉验证） | 无 ML 场景 | 因子挖掘启动时 |
| 分布式实验 | 单机并发池够 | 永远可能不需要 |
| Kelly sizer（研究项） | 对胜率/盈亏比估计误差极敏感，实盘起点不用 | 实验存量足够后作为一个研究课题 |
| 展示/应用分支迁 L1.5 取数 | 现状直读 L1 可用，迁移仅为统一 PIT 语义 | 顺带，不强制、不阻塞 |

**永不做**：

- **做空/多空双腿**：A 股现货实盘不可做空，研究无法实盘的策略违背
  "研究与实盘对齐"原则（统计层多空分析不受此限——event/bucket 照做）；
- **基本面因子（PE/PB/ROE）**：无财务数据源；数据源补齐后
  `bucket_analysis` 直接可用，届时重评。

## 2. 运行期再评估项（项目运行/实盘一段时间后回看）

（原《运行期再评估清单》B 组，全部为本期不做、触发条件驱动回看。）

### B1 失败标准与停机条件【优先级最高】
- 内容：为每条上线策略定义量化下线条件（示例：样本外滚动 12 个月
  Sharpe < 0 且回撤超线 → 降半仓/停机；实盘与回测偏离超 X% → 停线复查）；
  为研究方向定义止损（某方向连续 N 个实验无 confirmed → 关闭该方向）。
- 回看触发：①首次实盘并行期结束；②任何策略出现 >15% 回撤；③累计
  10 个以上实验仍未出现 confirmed。

### B2 上线目标与预期值
- 内容：写死"什么叫成功"（如跑赢 60/40、最大回撤 ≤ X%、年化换手 ≤ Y%），
  明确是验收参考而非收益承诺。
- 回看触发：准备把某策略真正用于实盘资金之前。

### B3 上线前必做实验集
- 内容：五组归因实验——①rank 消融（random vs freshness vs ER vs
  momentum）；②入场消融（v1 金叉 vs 随机入场 + 同止损）；③止损选型
  （= 首个课题：止损选型）；④持仓数/热上限扫描；⑤滑点敏感性（0.1/0.3/0.5%）。
- 回看触发：止损选型课题完成后，需回答"这套东西的 edge 到底来自哪一层"时。
- 附带观察项（仅观察不行动）：量化"价格 × 100 > 单仓预算的标的占比"，
  看可执行性约束吞掉多少信号。

### B4 研究议程与优先级机制
- 内容：由人给出 3–5 个研究方向 + 优先级 + 每方向预算，AI 在议程内
  自由，议程外想法进候选池。防止"研究很规范但都花在低价值方向"。
- 回看触发：AI 开始批量提实验、且出现"实验数量增长但无结论"时。

### B5 研究预算配额
- 内容：holdout 次数配额（如每季度 ≤ N 次）与准入规则（必须对准最终
  候选）。
- 回看触发：holdout 被消耗 ≥ 3 次后。

### B6 实盘最后一公里
- **偏离处置**：清单→手工执行的"未执行/部分执行"目前只被记录，不升级
  为待办；建议"偏离持续 N 天 → 报警 + 重新对齐动作（补买/补卖/接受并
  更新目标）"，否则实盘会静默漂移，而系统仍按目标持仓算热与仓位。
- **错过交易复盘**：unfilled（涨停买不到、买不起一手）已记录，但没有
  定期回看"错过之后涨跌如何"——若错过的多数上涨，说明可执行性约束在
  系统性吃收益。
- **亏损期行为约束**：回撤期最容易临时改规则；建议事前承诺（如"回撤
  15% 内不改参数"）+ 月度复盘模板，让系统在最想破坏它的时刻约束住人。
- 回看触发：实盘并行期第一周结束后。

### B7 单点故障与自检
- 内容：数据完整性扫描（缺口/异常值）；台账入账后的结构自检；备份
  **恢复演练**（备份已有，恢复流程未验证）；TickFlow 单点（曾发生
  会员过期事故）。
- 回看触发：首次发生数据异常/台账异常，或恢复演练从未做过且首次需要
  恢复时。

### B8 数据线时序细化
- 内容：不是"结论被 5 年锁死"，而是"长历史覆盖率只有约 1/7 池"。可做项：
  ①sample 起点前移（见 §3 C1，需用户决策）；②把"长历史子集"单独用于
  regime 分析；③数据线回填优先级按覆盖率收益排序。
- 回看触发：C1 决策时一并对齐。
