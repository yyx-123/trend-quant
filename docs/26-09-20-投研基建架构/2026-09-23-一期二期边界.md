# 一期 / 二期边界（投研基建分期判断）

> 日期：2026-09-23
> 地位：对架构稿 §4 阶段表与详设各处"二期/推迟"标注的统一收口文档。
> 用户定义：**一期 = 阶段 0–5**（把基建整个建完：台账 → 门面+引擎 →
> 回测器+策略库 → 实盘运行器 → L4 正式化）；**二期 = 明确暂时不做的项**。
> 本文档是分期判断的唯一出处；详设/架构稿中的相关表述以本文为准。

---

## 1. 判断原则

1. **硬依赖决定顺序，不决定分期归属**——一期内阶段 0–5 是实现顺序问题；
2. **"现在没有使用场景"不等于"不做"**——便宜且协议已预留的件，随对应
   阶段顺手做（多写两百行，不留版本裂缝）；
3. **正确性验证成本高的件（统计判定器）不因贵推迟**，但单独成任务、
   配 golden 测试——统计件错了不崩溃，只会让结论安静地撒谎；
4. **结构性边界才构成二期**：无数据源、无实盘价值、动引擎核心、
   需要一期产物存量（多策略、实验历史）才有意义。

## 2. 收进一期的项（原标注"二期"，现归入对应阶段）

| 项 | 落点 | 理由 |
|---|---|---|
| benchmark 策略入库（原阶段 3） | **并入阶段 2** | 阶段 2 验收本来就要 benchmark 同图；配置即策略，成本极低 |
| event_study / bucket_analysis 评估模块 | **与阶段 2 并行** | 只依赖台账（阶段 0）+ gateway（阶段 1），不依赖组合回测器；AI 研究不必等回测器 |
| vol_target / drawdown_throttle / buffered_rotation 模块 | 阶段 2（预置工具箱 §5.14） | 小模块，顺手预置 |
| walk-forward（window_mode 选项） | 阶段 5 | 回测器之上的窗口选项，无新依赖 |
| Sortino 推断 + 循环区块 bootstrap 引擎 | 阶段 5 | event_study 噪声带反正要用 bootstrap；趋势策略正偏收益下 Sortino 比 Sharpe 更对口 |
| MC 置信带 | 阶段 5 | bootstrap 引擎建成后边际成本极低 |
| FDR（BH 校正）/ PBO | 阶段 5 | 公式现成；实验存量少时只是不亮 |
| head_to_head（策略 A vs B 对照） | 阶段 5 | 回测两配置互算 deltas，回测器在就便宜 |
| recompute campaign + `supersedes` 指针（新记录指向被复核旧 verdict） | 阶段 5 | 机制简单（批量重跑 + 指针），字段已在表结构（详设 §6.3，R8 后语义） |
| 台账 Web 看板 UI | 阶段 5 | 阶段 5 本就含 L4 正式化；看板是人审/查看台账的刚需 |

## 4. 留在二期的项（明确暂时不做）

| 项 | 不做的理由 | 何时启动 |
|---|---|---|
| 工业化因子生产（表达式 DSL、因子库、相关性聚类、IC 流水线） | 决策 12：先把仓位/止损/组合风控做到及格 | 一期完成且基础研究线稳定后 |
| 加仓 lot 账 / 金字塔 / 网格模板 | 动引擎核心不变量（持仓模型、T+1 按批、round-trip 归因、网格无止损语义） | 引擎经基准 v1 验证后，二期第一件事 |
| 数据线（年度龙头池、退市股、历史拉深、ST/指数成分元数据） | 慢活：数据源能力验证（TickFlow 退市股/历史市值）先行 | 并行慢线，不阻塞一期 |
| meta-portfolio（策略组合/策略级轮换） | 需要多策略存量才有对象 | 策略库有 ≥3 条实盘级策略后 |
| 组合优化类 sizing（稳健优化/风险分解/反向优化） | 需协方差估计与优化器依赖；等风险够用 | 等风险被实验证明不够时 |
| 冲击成本滑点模型 | 小资金用不上；固定滑点+对账标定够 | 资金规模扩大到量级变化时 |
| purged/embargoed CV | 无 ML 场景 | 因子挖掘启动时 |
| 分布式实验 | 单机并发池够 | 永远可能不需要 |

## 5. 永不做的

- **做空/多空双腿**：A 股现货实盘不可做空，研究无法实盘的策略违背
  "研究与实盘对齐"原则（统计层多空分析不受此限——event/bucket 照做）；
- 基本面因子（PE/PB/ROE）：无财务数据源；数据源补齐后 `bucket_analysis`
  直接可用，届时重评。
