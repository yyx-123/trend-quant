```
- **数据源预留（决策 E4）**：评估模块当前唯一数据源是 gateway（行情面）。
  预留**第二数据源（交易/持仓面**：manual_trades、engine_fills 的实盘

```
  研究）使用——**仅预留，不实现；实现时点随"执行研究"需求定（一期不含，
  见 `2026-09-23-一期二期边界.md`）**；

## 6. S6（低）：§6.8 标题与分期文档"唯一出处"口径冲突

**位置**：详设 §6.8 标题与其首条。
**现状原文**：

```
### 6.8 明确不做（本版）

- 工业化因子生产全部（DSL/因子库/IC 流水线）；
```

**问题**：分期文档声明"本文档是分期判断的唯一出处"，而 §6.8 用"明确不做
（本版）"另立一套口径（且含"verdict 阈值自动调参""新增评估模块"这类
**永久性护栏**，与"二期项"性质不同）。
**改为**：

```
### 6.8 不做清单（永久性护栏 + 二期项；分期口径以 `2026-09-23-一期二期边界.md` 为准）

- 工业化因子生产全部（DSL/因子库/IC 流水线）【二期，见分期文档】；
```

并在该节末尾追加一句：

```
（本节混合两类：**永久性护栏**——verdict 阈值自动调参、新增评估模块、
分布式实验等；**二期项**——因子生产工业化、meta-portfolio、组合优化
sizing 等。分期的唯一出处是 `2026-09-23-一期二期边界.md`。）
```

**验收**：§6.8 不再自称唯一口径；两条护栏与二期项的性质被区分。
