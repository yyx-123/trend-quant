## 流程

1. 主审查人精读后端全部核心模块 + 3 个并行扫描代理（前端/测试/脚本文档运维）→ 主报告 v1
2. 两个独立评审代理分别核查主报告 → 评审意见落本目录
3. 一个独立盲审代理（不看本目录、不参考主报告）对整个仓库做同范围审查 → 比对查漏
4. 主审查人根据三方意见修订报告，直至评审代理与盲审代理均确认无遗漏、无错误结论
